# Backend - Prescription Hub

API NestJS para autenticacion, usuarios, prescripciones, PDF y metricas.

La guia completa de instalacion, variables de entorno y credenciales esta en [../README.md](../README.md).

## Comandos rapidos

```bash
npm install
npx prisma migrate dev
npm run prisma:seed
npm run start:dev
```

## URLs locales

- API: `http://localhost:3001/api`
- Swagger: `http://localhost:3001/docs`
